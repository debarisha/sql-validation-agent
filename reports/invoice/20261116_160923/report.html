AComparison semantics and limitations

Key matching
Equality on all key columns. Rows with a NULL in any key column are excluded from VC-04/VC-05 and surface in VC-02.
NULL handling
NULL = NULL is treated as a match; NULL vs a value is a mismatch (EXCEPT semantics).
Value normalisation
Values are cast to NVARCHAR before comparison: date/time types use CONVERT style 121 (ISO 8601, full precision), float/real use style 3 (17 significant digits), other types use CAST to NVARCHAR(MAX).
String comparison
Governed by the database collation (see Run metadata). Trailing spaces are ignored per ANSI padding rules; case sensitivity depends on the collation.
Duplicate keys
Duplicated keys multiply join output in VC-05; resolve VC-03 findings before interpreting VC-05.
Isolation
Statements run under the session default isolation level (READ COMMITTED unless RCSI is on). Concurrent loads during the run can produce transient differences.
